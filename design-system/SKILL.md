Journey Planner is a trip-planning platform for slow, conservation-minded travel through real local communities in Thailand. The visual identity is "Tropical Living Field Guide": calm, shaded-garden, a Marauder's-Map-style progressive reveal — never decorative fantasy, never a game world. Brand tone is calm, trustworthy, personal — not corporate, not childish, not clinical.

Only three things are genuinely locked, everything else is a reasoned starting point — read the README's "What's locked vs. candidate" section before treating anything as settled, especially the color tokens, typography, and the three-surface Station View model (explicitly NOT decided).

If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
