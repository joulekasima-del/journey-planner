Status pill for any state from the taxonomy: readiness, trust, booking, connectivity, route.

```jsx
<Badge tone="success">Ready</Badge>
<Badge tone="attention">Needs Attention</Badge>
<Badge tone="info">Estimate Available</Badge>
<Badge tone="danger">Booking Failed</Badge>
<Badge tone="neutral">Exploring</Badge>
```

Always paired with a dot by default — never rely on background color alone to carry the state (JP research 7).
