# Phase Rules

## Programme Planning

Defines the programme intent, scope, and execution model.

## Discovery

Clarifies product and architecture questions before decisions are locked.

## Architecture Freeze

Locks approved architecture and ends architecture discovery for the frozen scope.

## Repository Synchronization

Installs governance, indexes, specifications, and repository structure that reflect approved architecture.

## Implementation

Builds only against implementation-ready documentation.

## Verification

Checks that work matches approved scope and repository standards.

## Release

Publishes a verified milestone.

---

# Transition Rule

A phase may not silently absorb work from a prior phase.

If a synchronization task requires new architecture, it must return to review instead of continuing as implementation.
