# Project Identity

This project is a Journey Planner.

It is **not** a booking platform.

Booking exists only to support the journey.

The primary product is helping people design meaningful self-guided journeys through local communities.

Technology should quietly help people discover, plan, and respectfully experience local communities.

---

# Product Philosophy

Travel at the pace of the community, not the pace of the itinerary.

Every product decision should strengthen:

- hospitality
- conservation
- education
- geography
- local culture
- personal wellbeing
- calm exploration

# Source of Truth

The Bootstrap Pack is the project's highest-level documentation.

When conflicts occur:

# Repository Philosophy

Documentation exists to enable production.

Every document inside this Bootstrap Pack should reduce future uncertainty.

If a document does not improve implementation quality, onboarding, or long-term consistency, it should not exist.

---

# AI Philosophy

Artificial Intelligence is used to increase quality and consistency.

AI does not replace product thinking.

Responsibilities remain separated.

- ChatGPT
- Claude AI
- Claude Code
- Codex

Each has a clearly defined role.

No implementation agent may silently redesign approved product decisions.
