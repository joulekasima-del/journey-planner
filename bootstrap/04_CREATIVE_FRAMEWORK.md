# Journey Planner Creative Framework

Version: 1.0

Status: Active

---

# Purpose

This document establishes the permanent creative foundation adopted by the Journey Planner.

The Journey Planner does not create a new visual language.

Instead, it adopts the proven creative framework originally developed through Nature Base Workspace and treats it as a shared studio standard.

Business products may evolve.

The creative language should remain consistent.

---

# Creative Philosophy

The purpose of the creative framework is not decoration.

Its purpose is to create an atmosphere that supports calm thinking, meaningful exploration, and long-term trust.

Every visual decision should communicate:

- warmth
- craftsmanship
- quiet care
- clarity
- consistency

The interface should never compete with the journey.

It should quietly support it.

---

# Shared Studio Standards

The following documents are considered permanent studio standards.

They are adopted by this project without modification unless explicitly approved.

## Pixel Language v1

Defines the visual grammar of every asset.

Includes:

- Pixel Philosophy
- Cluster Language
- Negative Space Rules
- Shape Language
- Contrast Language
- Lighting Language
- Texture Language
- Animation Language
- Emotional Language
- AI Translation Layer
- Forbidden Language

Pixel Language v1 is the highest authority for visual production.

---

## Master Palette v1

Every asset must use the shared Master Palette.

Rules:

- One palette for the entire world.
- No true black.
- Permanent moonlight.
- Warm lantern accents.
- Colour consistency across all modules.

No project-specific palettes may replace the Master Palette without explicit approval.

---

## Art Direction Guide

Defines:

- artistic vision

- visual hierarchy

- production quality expectations

This document protects long-term artistic consistency.

# Companion Philosophy

The Companion is part of the studio identity.

It is not tied to a specific business.

Core principles:

- observes, never commands
- calm presence
- reassuring
- supportive
- subtle
- never distracting

The Companion exists to reduce anxiety rather than increase engagement.

Future projects may reinterpret appearance while preserving behaviour.

---

# World Philosophy

Every project using this framework exists within the same visual universe.

Core principles:

- one permanent moon
- warm lantern light
- handcrafted environments
- calm atmosphere
- slow movement
- readable composition

Different products may introduce different locations while preserving these universal rules.

---

# Animation Philosophy

Animation supports atmosphere.

It never becomes entertainment by itself.

Movement should feel:

- gentle
- asynchronous
- restrained
- believable

Examples:

- lantern flicker
- steam
- leaves
- stars
- water
- breathing
- blinking

Nothing should bounce, vibrate, or aggressively loop.

Animation should encourage calm observation.

# AI Philosophy

Artificial Intelligence assists production.

It does not replace artistic direction.

AI responsibilities:

- exploration
- composition
- variation
- iteration

Human responsibilities:

- selection
- refinement
- pixel cleanup
- quality judgement
- final approval

Every production asset requires human approval.

---

# Source Preservation

Every approved production asset maintains:

- original AI reference
- Aseprite source
- production PNG
- version history

Creative work must remain reproducible.

No approved asset should lose its source history.

---

# File Organisation

Every asset category maintains:

- source/
- approved production assets
- documentation
- naming consistency

Naming follows structured asset identifiers.

Examples:

terrain_grass_01

architecture_cabin_01

prop_lantern_01

companion_idle_01

Consistency is more important than creativity in file naming.

---

# Creative Review

Every visual asset should answer "yes" to the following questions.

- Does it follow Pixel Language v1?
- Does it use the Master Palette?
- Does it preserve the permanent lighting philosophy?
- Does it support readability?
- Does it belong to the same visual family?
- Does it communicate warmth and quiet care?
- Would it feel natural beside every existing asset?

If not, the asset should return to production.

Future products should inherit this creative system rather than creating new artistic identities unless a different visual direction is an explicit strategic decision.

One creative language.

Many products.

One recognizable studio identity.

---

# Amendment Rule

Changes to the Creative Framework require explicit locked approval.

Individual projects may extend the framework but must never silently replace or contradict the shared studio standards.
